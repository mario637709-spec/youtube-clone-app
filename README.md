# YouTube Clone

A full-stack YouTube clone built with React and Node.js.

## Features
- User authentication (register/login)
- Video upload and playback
- Comment system
- Like/dislike functionality
- User channels
- Video search
- Responsive design

## Tech Stack
**Frontend:**
- React
- React Router
- Context API

**Backend:**
- Node.js
- Express
- MongoDB
- JWT Authentication

## Installation

### Backend
```bash
cd backend
npm install
# Create .env file with:
# MONGO_URI=your_mongodb_connection_string
# JWT_SECRET=your_secret_key
# PORT=5000
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm start
```
